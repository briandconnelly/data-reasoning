# Decision records

Why the skill is shaped the way it is, one decision per file, in the format the sibling skills use: context, the positions considered, what settled it, and a reopening condition.

- [001-name.md](001-name.md) — Name: decision-analysis.
- [002-authority-map.md](002-authority-map.md) — Authority map with the sibling skills.
- [003-numeric-provenance-policy.md](003-numeric-provenance-policy.md) — Numeric provenance policy.
- [004-binary-scope.md](004-binary-scope.md) — v1 scope: one binary proposition, two actions.
- [005-voi-definition.md](005-voi-definition.md) — Value of information is net expected improvement, not flip probability.
- [006-verdict-never-authorizes.md](006-verdict-never-authorizes.md) — A verdict is a recommendation, never an authorization.
- [007-evidence-sweep-and-loss-orientation.md](007-evidence-sweep-and-loss-orientation.md) — The likelihood-ratio sweep, a fifth verdict, and loss orientation.
- [008-ruled-out-state.md](008-ruled-out-state.md) — A state that an observation rules out (accepted 2026-11-25, #114).

These records are for maintainers; a rule's home is `../SKILL.md`, and these files point rather than restate.
Paths under `tests/`, `scripts/`, and `jev/` in these records refer to the development repository (<https://github.com/briandconnelly/data-reasoning>); an installed plugin does not carry them.
