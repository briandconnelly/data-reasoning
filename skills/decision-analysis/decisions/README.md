# Decision records

Why the skill is shaped the way it is, one decision per file, in the format the sibling skills use: context, the positions considered, what settled it, and a reopening condition.
These records are for maintainers; a rule's home is `../SKILL.md`, and these files point rather than restate.
Paths under `tests/`, `scripts/`, and `jev/` in these records refer to the development repository (<https://github.com/briandconnelly/data-reasoning>); an installed plugin does not carry them.
