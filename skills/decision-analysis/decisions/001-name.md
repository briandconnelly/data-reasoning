# 001 — Name: decision-analysis

Status: accepted, 2026-08-09.

## Context

The skill needed a name alongside `exploratory-data-analysis`, `hypothesis-driven-analysis`, and `causal-identification-review`.
Candidates: `decision-analysis`, `bayesian-decision-analysis`, `decision-under-uncertainty`.

## Decision

`decision-analysis`: the established field name for choosing under uncertainty with explicit probabilities and losses, parallel to the siblings' naming rhythm.
`bayesian-decision-analysis` was rejected because the numeric policy (`../SKILL.md` § Numeric Policy) is closer to robust Bayes than textbook Bayes, and the prefix invites method debates the skill does not host.
`decision-under-uncertainty` was rejected as wordier in routing prose with no added precision.

## Reopening condition

Triggering evidence that users say "Bayesian" and the description fails to route them here.
