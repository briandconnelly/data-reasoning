Use for any request about a named entity — an account, branch, customer, program, collection, or segment — that asks what is going on with it, in whatever words: "give me an overview of this branch", "give me a rundown on this account", "tell me about this program", "what's the story with this segment", "give me context on this collection", "profile this account". The phrasing does not matter; an overview, a rundown, a picture, a story, or a profile of a named entity all belong here. Also use when handed a dataset, log, or event stream to explore — "what's in this data", "anything interesting or anomalous". Runs a phased exploration: orient on schema, quality, and coverage before interpreting; a looks register for every output; leads that carry the search context that produced them. Do not use when a named effect needs explaining or a claim needs checking ("why did X change", "is it true that") — that belongs to hypothesis-driven-analysis. Not for bounded descriptive queries the records settle.
