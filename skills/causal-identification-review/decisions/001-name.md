# 001 — Name: `causal-identification-review`

Status: accepted, 2026-08-08.

## Question

What should the new skill be called, given the naming has to do real work: it must read as a discipline rather than a methods course, and it must not be mistaken for the excluded prospective-experiment-design candidate?

## Positions

*`causal-identification-review` (adopted).*
States the deliverable — a review of identification — rather than the field the deliverable is about, so the textbook/discipline line the candidate analysis insists on is enforced from the name's first word.
It also reads apart from prospective-design mechanics, which this plan excludes (see 003).

*`causal-identification` (rejected).*
Names a topic rather than an activity.
The candidate analysis's framing test — a candidate that is really a methods textbook fails, however useful the methods are — applies as much to the name as to the body text: a topic name invites a reader to expect coverage of the topic, which is exactly the textbook shape this skill has to avoid.

*`causal-design-review` (rejected).*
The 2026-08-08 Codex cross-model critique judged this name acceptable on its own but ambiguous against the excluded prospective-experiment-design candidate, since "design" names both a causal-identification design and an experiment design equally well.
It preferred `causal-identification-review` for keeping that distinction unambiguous.

## What settled it

The candidate analysis's own textbook/discipline test, applied to the name rather than only the body, plus the Codex critique's direct comparison of the two design-adjacent candidates, which found `causal-design-review` ambiguous against the thing this skill explicitly is not.

## Reopening condition

If a future skill in this plugin needs a name that collides with `causal-identification-review` under normal routing-description phrasing, or if usage shows the "review" framing is read as excluding routes the skill actually performs (see 003's construct and bound routes), the name is worth revisiting.
